# Model Context Protocol (MCP) Configuration

This directory contains configurations and implementations for Model Context Protocol (MCP) servers that can be used with Claude Code.

## Structure
- `servers/` - Individual MCP server implementations
- `config/` - Configuration files for MCP connections
- `clients/` - Client implementations for connecting to MCP servers

## Purpose
MCP allows Claude to connect to external tools and services to enhance its capabilities. This setup will allow for integration with various development tools, services, and custom functionality.
