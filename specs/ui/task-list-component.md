# UI Component: Task List

## Purpose
Display a list of tasks with filtering and sorting capabilities.

## Props/Inputs
- tasks: Array of Task objects
- onTaskUpdate: Function to handle task updates
- onTaskDelete: Function to handle task deletion
- filter: Current filter state (all, pending, completed)

## Features
- Display task title and status
- Show completion checkbox
- Filter tasks by status
- Sort tasks by creation date or title
- Responsive design for mobile and desktop

## Styling
- Use Tailwind CSS classes
- Follow design system guidelines
- Accessible color contrast
- Keyboard navigation support
